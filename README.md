# 西方哲学研读

个人西方哲学学习研究项目，使用 [LLM Wiki 模式](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 组织。

## 这是什么

不是简单的笔记堆叠，而是一套**会持续生长的知识网络**：每条笔记、每本书、每次思考都会经过提炼、链接、入库，最终沉淀为个人可检索的"第二大脑"。

## 快速开始

1. 把阅读笔记 / 书摘 / 读后感 / PDF 摘录放入 **`raw/`**（命名格式见 `raw/README.md`）
2. 让 AI 进行 **Ingest**：自动提炼 → 创建/更新 Wiki 页 → 建立链接 → 更新索引
3. 提问时（**Query**），AI 优先基于 Wiki 回答；新结论可回写
4. 定期（**Lint**）：清理孤立页面、补全反向链接、修正冲突信息

## 工作流速查

| 工作流 | 触发 | 作用 |
|--------|------|------|
| **Ingest** | 提供了新原始资料 | 提炼并更新 Wiki |
| **Query** | 提问 | 基于 Wiki 回答，新结论可回写 |
| **Lint** | 主动要求 | 检查孤立页、死链、冲突、缺漏 |

## 目录导览

| 目录 | 用途 |
|------|------|
| `CLAUDE.md` | 给 AI 的项目章程 + Wiki 规范 |
| `raw/` | 原始资料（append-only） |
| `wiki/` | **Wiki 主体**（核心知识库） |
| `templates/` | 各类型页面模板 |
| `meta/` | 方法论、术语表、进度 |
