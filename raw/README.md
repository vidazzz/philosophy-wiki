# raw/ — 原始资料仓库

本目录是**只增不改**的事实源。所有原始材料（读书笔记、书摘、读后感、PDF 摘录、课堂笔记、对话记录等）都先放在这里，由 AI 进行 **Ingest** 后提炼到 `wiki/`。

## 文件命名

`<YYYY-MM-DD>-<主题>.md`

示例：
- `2026-08-13-理想国读书笔记.md`
- `2026-08-15-黑格尔精神现象学摘要.md`

## 文件格式建议

```markdown
# 标题
<!-- 日期: YYYY-MM-DD -->
<!-- 来源: 书名/章节/页码 -->

## 摘录或要点

...

## 我的思考

...
```

## 注意事项

- **不要修改旧文件**：raw/ 是 append-only。如需修正，请新增补充文件并在原文件加注释说明。
- **不要在 raw/ 里直接写 Wiki 页面**：那是 `wiki/` 的工作。
- **可以保留粗糙**：原始笔记不需要写得漂亮，AI 会帮你提炼。
- **明确标注来源**：每段摘录要注明来自哪本书、哪一页；自己的思考要标"我的思考"。
