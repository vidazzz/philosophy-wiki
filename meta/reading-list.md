## 五、选读顺序建议（综合）

如果您希望按"由浅入深"系统学习：

**第一阶段**（入门）：Sophie's World → 赵敦华《西方哲学简史》 → 张志伟《西方哲学史》

**第二阶段**（核心 primary）：
- 柏拉图：《苏格拉底的审判》→ 《理想国》→ 《会饮》→ 《斐多》→ 《泰阿泰德》
- 亚里士多德：《尼各马可伦理学》→ 《形而上学》
- 罗马：西塞罗《论法律》→ 《论共和国》→ 《学园派》→ 《论义务》

**第三阶段**（专题深入）：
- 自然法传统：奥古斯丁 → 阿奎那 → 洛克 → 菲尼斯
- 哲学-科学关系：柏拉图《泰阿泰德》→ 亚里士多德《形而上学》→ 维特根斯坦《逻辑哲学论》→ Quine《两个教条》→ 海德格尔

**第四阶段**（现代哲学）：
- 笛卡尔 → 康德 → 黑格尔 → 现象学 → 分析哲学 → 当代政治哲学
