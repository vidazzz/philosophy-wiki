    理性主义¶

    基本信息¶

    • 时期：17 世纪（约 1600-1750）—— 巴洛克时期的核心哲学运动
    • 别称：欧陆理性主义（Continental Rationalism，与英国经验主义 Empiricism 对照）
    • 核心主张：知识源于理性（reason），而非感官经验
    • 方法论：以数学的严格演绎方式建立哲学体系

    代表人物¶

    • 笛卡尔（1596-1650）—— 奠基人，"现代哲学之父"
    • 斯宾诺莎（1632-1677）—— 实体一元论的极致
    • 莱布尼茨待创建（1646-1716）—— 单子论 + 前定和谐

    用户笔记原文（2026-08-26）： 然后是 17 世纪最伟大的两位哲学家笛卡尔和斯宾诺莎。（注：第 3 位最伟大者通常被认为是莱布尼茨待创建）

    核心特征¶

    1. 知识的来源：理性 vs 经验¶

    • 理性主义：心灵本身具有天赋观念（innate ideas），无需感官输入
    • 经验主义：所有知识来自感官经验（洛克"白板说"，休谟彻底化）

    2. 方法论：数学演绎¶

    • 笛卡尔：希望用数学方法进行哲学性思考，运用证明数学定理的方式证明哲学真理（用户笔记 2026-08-26）
    • 斯宾诺莎：《伦理学待创建》用"几何学方式证明"（ordine geometrico demonstrata）
    • 莱布尼茨待创建：提出"普遍文字"（characteristica universalis）—— 所有理性推论可还原为计算

    3. 形而上学基础¶

    哲学家 本体论 认识论 核心论证
    笛卡尔 二元论（res cogitans + res ext） cogito + 清晰明白的观念 方法论怀疑
    斯宾诺莎 一元论（Deus sive Natura） 理性直觉 + 几何学证明 实体唯一
    莱布尼茨待创建 单子论 + 前定和谐 充足理由律 多元单子

    4. 与科学/数学的紧密联系¶

    用户（2026-08-26）的元观察：理性主义者同时是数学家/科学家

    人物 数学/科学贡献 哲学贡献
    笛卡尔 解析几何（坐标系） 普遍怀疑 + 二元论
    斯宾诺莎 镜片研磨（光学技术） 一元论 + 决定论
    莱布尼茨待创建 微积分（独立发明）+ 二进制 单子论 + 前定和谐

    这反映了 17 世纪"自然哲学 = 物理学"的学科未分化状态。

    主要议题¶

    • 天赋观念 vs 经验输入（与经验主义争论）
    • 理性认识的可靠性：我们能否仅凭理性把握实在？
    • 数学与形而上学的连续性：数学结构能否揭示存在结构？
    • 身心关系：理性主义如何解释？

    关键概念¶

    • cogito待创建（我思故我在）
    • 天赋观念待创建
    • 清晰明白的观念待创建
    • 单子待创建（莱布尼茨）
    • 前定和谐待创建（莱布尼茨）
    • 二元论 / 一元论
    • 决定论
    • 自然法则待创建
    • 形而上学待创建

    兴衰¶

    兴起（17 世纪）¶

    • 文艺复兴以来科学革命的副产品
    • 笛卡尔的方法论怀疑 + 数学化哲学
    • 伽利略、牛顿的数学化自然观的影响

    鼎盛（17 世纪晚期-18 世纪）¶

    • 斯宾诺莎、莱布尼茨待创建集大成
    • 同时期的英国经验主义（洛克、休谟）形成对照

    转折（18 世纪）¶

    • 休谟的彻底经验论冲击了理性主义的基础
    • 康德待创建试图综合：先验综合判断

    现代影响¶

    • 德国观念论待创建（黑格尔、谢林）：理性主义的复兴与改造
    • 现象学待创建（胡塞尔）：回到"事情本身"（某种意义上是笛卡尔式理性主义）
    • 分析哲学：莱布尼茨的逻辑学传统 → 现代符号逻辑
    • 现代心智科学：理性主义 vs 经验主义仍是核心争论

    与其他流派的关系¶

    • 对立：经验主义（英国传统）—— 洛克、贝克莱、休谟
    • 延伸：德国观念论待创建（黑格尔）—— 理性主义的德国复兴
    • 修正：康德待创建的先验哲学 —— 综合两派
    • 平行：
    • 斯多亚学派（古代理性主义传统）
    • 新柏拉图学派（理性主义 + 神秘主义）

    待研究问题¶

    • ⚠️ "理性"（reason）一词在不同理性主义者那里的含义差异（笛卡尔 = 清晰明白，斯宾诺莎 = 几何学演绎，莱布尼茨 = 计算）
    • ⚠️ 理性主义 vs 经验主义的争论在 认知科学待创建 中的现代回响（先天 vs 后天，nature vs nurture）
    • ⚠️ 莱布尼茨待创建 vs 斯宾诺莎 的决定论分歧：莱布尼茨的"前定和谐"是否算一种救赎？
    • ⚠️ 笛卡尔的"cogito" 与 莱布尼茨的"充足理由律"的关系
